# lit-canon-fetch

The small browser runtime behind clients generated by
[lit-canon-api](https://github.com/mathisarends/lit-canon/tree/main/packages/api):
JSON bodies, query strings, request defaults, RFC 9457 problem details and a typed
`ApiError`. No dependencies.

```bash
pnpm add lit-canon-fetch
```

Configure it once during application startup:

```ts
import { configureApiFetch } from "lit-canon-fetch";

configureApiFetch({
  baseUrl: "https://api.example.com",
  // Static headers, or a sync or async function called before every request.
  headers: async ({ url, method }): Promise<HeadersInit> => ({
    authorization: `Bearer ${await session.token()}`,
  }),
});
```

Generated API functions and query options then use these defaults. Handle HTTP
failures with `ApiError`:

```ts
import { ApiError } from "lit-canon-fetch";

try {
  await products.getProduct("p-1");
} catch (error) {
  if (error instanceof ApiError && error.status === 404) {
    // error.problem holds the problem details, if the server sent any.
  }
}
```

| Export              | Purpose                                                            |
| ------------------- | ------------------------------------------------------------------ |
| `configureApiFetch` | Set `baseUrl`, `credentials`, `headers` and `fetch` for `apiFetch` |
| `apiFetch`          | The request function generated clients call                        |
| `createApiFetch`    | An independent `apiFetch` with its own configuration               |
| `ApiError`          | Thrown for HTTP failures, with `status` and `problem`              |
| `ApiProblem`        | RFC 9457 problem details type                                      |
| `ApiRequestOptions` | Request options: `fetch` options plus `body` and `query`           |
| `ApiFetchConfig`    | Configuration type                                                 |

`null` and `undefined` query values are omitted, also inside arrays. See the
[runtime guide](https://github.com/mathisarends/lit-canon/blob/main/docs/runtime.md)
for details.
