# Documentation

Choose the path that matches what you want to do.

## Use the generated client in an application

1. [Getting started](getting-started.md): install the package, generate a client and
   use the options in a Lit component.
2. [Configuration and CLI](configuration.md): customize features, authentication,
   query aliases, problem types and output ownership.
3. [Fetch runtime](runtime.md): configure requests, handle errors or bring your own
   fetch mutator.

See [OpenAPI requirements](openapi.md) when preparing the specification or fixing a
generation error. The [catalog example](../examples/catalog/README.md) shows the
input, generated output and component together.

## Work on this repository

- [Development](development.md): setup, verification commands and repository conventions.
- [Architecture](architecture.md): generation flow and a map of the source files.
- [Agent guide](agents.md): where to start, behaviors to preserve and checks to run.

The guides describe the current implementation. When behavior changes, update the
relevant page alongside the code and examples.
